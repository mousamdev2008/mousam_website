# Book Reading List Application

## Description
A responsive web application that helps students manage their personal reading lists.

## Features
- Add books with their titles and reading status.
- Change status to Want to Read, Reading, or Finished.
- Filter books by reading status.
- Prevent duplicate book titles, ignoring case and extra spaces.
- Limit book titles to 60 characters.
- Delete individual books.
- Display total books, currently reading, and finished counts.
- Responsive design for desktop and mobile.

## Technologies Used
- React
- TypeScript
- HTML and CSS
- Vite

## How to Run Locally
1. Install Node.js.
2. Open a terminal in the project folder.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL shown in the terminal.
