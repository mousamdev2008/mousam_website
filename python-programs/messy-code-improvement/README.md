# Messy Python Code Improvement

## Description
This project demonstrates how messy Python code can be improved using Cursor AI. The original code was refactored into separate functions to improve readability and maintainability.

## Features
- Calculates the sum of numbers.
- Calculates the average of numbers.
- Finds the maximum number.
- Uses meaningful variable and function names.
- Includes comments and docstrings.

## Technologies Used
- Python 3
- Cursor AI

## How to Run
1. Install Python 3.
2. Open the terminal in this folder.
3. Run the following command:

```bash
py messy_code.py
```

## Learning Outcome
Learned how AI-assisted code refactoring can improve code structure, readability, and maintainability while preserving the program's results.
