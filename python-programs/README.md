
# Python Programs Collection

## Description
This project contains basic Python programs created to practice programming concepts and logic building.

## Programs Included

### 1. Factorial
Calculates the factorial of a number using a loop. It also handles negative inputs.

### 2. Fibonacci Series
Prints the required number of terms in the Fibonacci series.

### 3. Structure-to-Dictionary Conversion
Uses a Python class to store student details and converts the object's attributes into a dictionary using `__dict__`.

## Technologies Used
- Python 3
- Classes and Objects
- Loops
- Conditional Statements
- Dictionaries

## How to Run

1. Install Python 3.
2. Open the terminal in the project folder.
3. Run the required program using:

```bash
py factorial.py
```

For the other programs, use:

```bash
py fibonacci.py
py structure_to_dictionary.py
```

## Learning Outcome
Practiced loops, conditional statements, classes, objects, and dictionary conversion in Python.
