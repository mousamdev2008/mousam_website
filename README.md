# Personal Portfolio Website

## Project Description
A personal portfolio website developed to showcase my profile, education, technical skills, and programming projects as a B.Tech Computer Science and Engineering student.

## Features
- Personal introduction and About Me section
- Technical skills section
- Five project cards
- Search projects by name or technology
- Light and dark mode toggle
- Contact section
- Links to project demonstrations and source code
- Responsive design for desktop and mobile devices

## Projects Included
1. **Python Programs Collection** — Factorial, Fibonacci series, and structure-to-dictionary conversion.
2. **Messy Python Code Improvement** — Refactoring Python code using Cursor AI.
3. **Bug Fixing Using Cursor AI** — Identifying and correcting a logical error.
4. **Interactive Quiz Application** — A quiz built using HTML, CSS, and JavaScript.
5. **Book Reading List Application** — A reading list with status filters, duplicate prevention, deletion, and summary counts.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Cursor AI
- GitHub
- Vercel

## How to Run Locally
1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
