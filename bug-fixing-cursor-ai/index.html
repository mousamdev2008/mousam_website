Bug Fixing Using Cursor AI

This project demonstrates how an incorrect Python program can be debugged and improved using Cursor AI.

Problem

The program calculates the sum of numbers. The bug occurs when the total is replaced instead of accumulating each number.

Incorrect Code

numbers = [10, 20, 30, 40, 50]
total = 0

for i in range(len(numbers)):
    total = numbers[i]

print("Sum of numbers:", total)

Corrected Code

numbers = [10, 20, 30, 40, 50]
total = 0

for i in range(len(numbers)):
    total += numbers[i]

print("Sum of numbers:", total)

Explanation

The incorrect statement total = numbers[i] replaces the previous value in every iteration.

Using total += numbers[i] adds each number to the running total.

Expected output: Sum of numbers: 150
